# Cloud Task Manager

## Project Overview
Cloud Task Manager is a simple web application
developed using HTML, CSS, and JavaScript.

It helps users manage their daily tasks through
a simple and responsive interface.

## Objectives
- Develop a simple web application.
- Create a responsive user interface.
- Test the application's basic functionality.
- Deploy the application to a cloud hosting platform.
- Learn the basics of cloud deployment.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Pages

## Features
- Add tasks
- Mark tasks as completed
- Undo completed tasks
- Delete tasks
- Responsive design

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Add, complete, or delete tasks.

## Deployment
The application can be deployed using GitHub Pages.
